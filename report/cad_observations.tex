% 3D CAD and plots: observations from the recorded GUI session (6 design runs).
The recorded session (\videoref) has six design runs on the baseline bridge: Mumbai, span 30~m, carriageway 7.5~m, skew 0\textdegree, Optimized. Runs 1--3 use identical inputs, run 4 uses custom steel and concrete, run 5 uses M45 deck concrete, and run 6 has the same inputs as runs 1--3 after Additional Inputs was opened and saved with no edits. The still frames below are taken from that recording.

\paragraph{3D model.} After every run the 3D model was rebuilt with 4 girders, overall width 8.40~m, girder spacing 2.10~m and a 250~mm deck, matching the homepage inputs and the 2D cross-section (4 girders at 2.10~m, overhang 1.05~m). The part toggles (Bridge, Girder, Deck, Cross Bracing, Crash Barrier) isolate each member group, and hovering over a member shows its data.

\begin{figure}[H]\centering
\includegraphics[width=0.80\linewidth]{figures/cad_bridge_run1.png}
\caption{3D model after run 1: 4 plate girders, cross bracing, deck and crash barriers.}\label{fig:cad}
\end{figure}

\paragraph{Cross-bracing spacing: four different values in one session.} For the same bridge, with no input edited:
\begin{itemize}[nosep]
\item the 2D plan view before design is labelled \emph{Bracing Spacing = 3.50~m}, but it draws 9 equal bays over 30~m, i.e.\ 3.33~m (Figure~\ref{fig:plan});
\item the 3D model's tooltip gives \emph{Spacing: 3000.00~mm} (Figure~\ref{fig:tooltip}); the CAD uses a 3~m constant (\gh{93});
\item the design's LTB check uses a 3.0~m fallback, while the Additional Inputs dialog and report Table~2.7 show 15.0~m (\issue{01}).
\end{itemize}
The mismatch between the plan label and the plan drawing is a new observation from the recording; I have not filed it separately.

\paragraph{Plots.} \emph{Output Dock $\rightarrow$ Analysis and Design Results Summary $\rightarrow$ Analysis Results} shows the bending moment, shear force and deflection diagrams of one girder for a chosen load combination. \emph{Member ID} lists Girder~1 to Girder~4, the four physical girders, whereas the design checks run on 6 lines, including the two deck-edge lines (\issue{03}). The diagrams show \issue{03} directly. Girder~2's self-weight bending moment is 205.2~kNm at midspan (Figure~\ref{fig:plots}). For the girder's own mass of 274~kg/m, shown in the Details tab (2.69~kN/m), $wL^2/8 = 302$~kNm, so the plotted moment is 0.68 of it. Part of the girders' self-weight is carried by the edge lines.

\paragraph{Output Dock.} The force-component selector at the top of \emph{Girder Analysis Results} is a $3\times3$ grid of radio buttons with no labels, so the user cannot tell which force or moment each one selects. Observed in the recording; not filed.
